# Настройка OPC UA

Реальный OPC UA client в текущей ревизии не завершён. Тип `opcua` честно возвращает `Unknown`, а не имитирует данные. До включения необходимо подтвердить endpoint, security policy/mode, способ аутентификации, доверие сертификатам, namespace URIs и NodeIds.

Не отключайте проверку сертификата в production. Пароли и private keys не сохраняйте в конфигурации или логах. План интеграции и неизвестные параметры также перечислены в `masterscada-integration.md`.
