# Интеграция с MasterSCADA 4D

MVP намеренно не предполагает неизвестные детали MasterSCADA. Для реального внедрения необходимо получить и проверить:

- точные имена контролируемых процессов и Windows-служб;
- пути и правила ротации архивных файлов и логов;
- кодировку логов и подтверждённые шаблоны ошибок;
- OPC UA endpoint, security policy/mode, способ аутентификации, сертификаты и trust store;
- namespace URI/index, NodeId и типы данных сигналов, права только на чтение;
- выбранную и одобренную OPC UA библиотеку;
- формат quality и семантику source/server timestamps;
- тип СУБД архива, подтверждённые таблицу/колонки, формат timestamp и доступ read-only;
- допустимую задержку архива, частоту сигналов, диапазоны, sentinel и допуски от технологов.

До получения этих сведений `OpcUaCurrentDataSource` возвращает ошибку `OPC UA data source is not configured`, а SQLite adapter остаётся выключенным при пустой схеме. Никакие миграции и изменяющие запросы к архиву не выполняются.
